Data freshness is how old the newest row in a table is relative to now, and completeness is whether the expected rows arrived. This explainer covers how to define an SLA for both, how to check them inside the pipeline with a freshness check and a row-count check, and where dbt source freshness, Bruin custom checks, and observability tools fit.
