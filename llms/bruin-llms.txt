# Bruin

> Bruin is an end-to-end, open-source AI data platform that consolidates data
> ingestion, SQL/Python transformation, orchestration, quality checks, column-
> level lineage, and natural-language analytics into a single Git-native tool.
> Its primary developer surface is the open-source Bruin CLI (Apache-2.0) plus
> the ingestr data-copy tool, a Python SDK, a VS Code extension, a GitHub Action,
> and a built-in Model Context Protocol server (`bruin mcp`). Bruin Cloud adds a
> hosted control plane, scheduling, and dashboards. SOC 2 Type 2 audited; GDPR.
